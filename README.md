#### 주요 실습 내용
1. **매출 (Revenue) 열 추가**: `UnitPrice`와 `Quantity`를 결합하여 매출 계산

3. **카테고리별 매출 통계 집계**: 카테고리별 매출의 합계, 평균, 거래 건수 산출
